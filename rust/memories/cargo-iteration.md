While iterating, run `cargo check -q -p <crate>`; before finishing, run `cargo clippy -q -p <crate> --all-targets -- -D warnings` and `cargo test -q -p <crate>` for each crate you touched. Never use `--release` or `--all-features` while iterating, and don't run the whole workspace unless asked. Run one cargo command at a time per checkout: when cargo says it is blocking on a file lock, wait, never kill or retry. Run commands likely to take over 90 seconds (cold builds, a first test run) in the background, then read the first errors, not the tail.
