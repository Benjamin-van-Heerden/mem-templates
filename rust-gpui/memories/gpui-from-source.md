Use the `gpui` skill (its `outdated-patterns` reference lists what changed), the vendored `gpui-kit` skill, and when unsure the locked source under `~/.cargo/registry/src/index.crates.io-*/gpui-pre-<version>/` and `gpui-kit-<version>/`. Never translate an older GPUI, React or CSS example by analogy.
