Run the app with `bun run dev`, which serves it through portless at this checkout's URL (`bunx portless get <package name>`; a Git worktree gets `<branch>.` in front), and point browsers and checks there; `bun run smoke` without a URL checks it. Never hard-code `localhost:3000` or a port: in development `next.config.ts` sets `NEXT_PUBLIC_APP_URL` and `BETTER_AUTH_URL` from portless, and `.env.local` keeps `http://localhost:3000` only for `bun run start` and `PORTLESS=0 bun run dev`.

To show the app in the Claude desktop app's browser pane, start `bun run dev` through the project's `.claude/launch.json` entry, then open this checkout's URL with the preview tool's `preview_start`, `url` set to the output of `bunx portless get <package name>`. Ignore the blank tab the entry opens: the shared portless proxy always holds its port (1355), so the preview tool takes the entry's port to be busy and moves it to one nothing serves. Opening the URL through `preview_start` also registers the local origin with the pane, whose `navigate` refuses local origins it was not given. This works in Git worktrees too, since `portless get` prints the checkout's own URL.
