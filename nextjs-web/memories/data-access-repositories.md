All queries live in `src/db/repositories/<entity>.ts`: server-only functions that take the database handle (`db` or a transaction's `tx`) first, return narrow types and do no auth or caching. Feature `data.ts` modules, Server Actions, Route Handlers and workflow steps call them and own auth, caching and transactions; outside `src/db/` and the better-auth config nothing imports `drizzle-orm` or `@/db/schema`, and pages and components never import `@/db/*`. ESLint enforces this (see `drizzle-neon`).
