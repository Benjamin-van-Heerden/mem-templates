# Setup: nextjs-web

This project uses the `nextjs-web` template and has not been set up yet. Setting it up is the first task of the session.

1. If there is no `package.json` yet, follow "New project" in the `nextjs-setup` skill from step 1. If the project already has a Next.js app, set up only the pieces it is missing ("Adding a piece to an existing project" in the same skill), or none.
2. Finish with the skill's verification: `bun run typecheck`, `bun run build`, and signing in against the local database.
3. Replace the example `notes` feature and set the app's name and brand tokens, with the user.
4. Delete this file (`.mem/docs/setup.md`), and commit it together with the setup. mem then excludes it from the template, so it does not come back.
